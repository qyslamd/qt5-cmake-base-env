# 模板使用指南

本仓库本身即"Qt5 + CMake + Ninja"项目基础模板（Windows 主线为 MSVC，
同时支持 Linux/GCC 构建，见下文"Linux 构建"）。基于它新建项目时，按下面
清单修改即可，其余构建设施（版本管理、部署、打包、代码统计、单元测试）
无需改动。

## 必改项

复制仓库后必须修改的位置：

| # | 位置 | 改成什么 |
|---|------|----------|
| 1 | `CMakeLists.txt` 顶部 `project()` 与 `APP_ORG_NAME` / `APP_APP_NAME` | 项目名、版本号、描述。`APP_APP_NAME` 默认跟随项目名；这两项决定单实例键、`%LOCALAPPDATA%` 数据目录与安装包的卸载路径，改名后旧数据目录不会自动迁移 |
| 2 | `local.cmake`（仅 Windows） | 本机 Qt 安装路径（x64/x86 两条）。该文件不入库；首次 configure 时若不存在会自动生成并报错提示，改完重跑。Linux 不读取该文件 |
| 3 | `src/app/CMakeLists.txt` 的 `TARGET_NAME` | 主程序目标名，影响 exe 文件名、`run_app.bat` 与打包脚本 |
| 4 | `src/app/CMakeLists.txt` 的 `ISCC_APP_ID`（x64/x86 两处） | 每个项目必须换新 GUID，否则安装包互相覆盖。配置阶段检测到默认值会输出 WARNING；可用 pwsh 执行 `[guid]::NewGuid()` 生成 |
| 5 | `cmake/make_install_package.iss.in` 的 `MyAppName` | 安装包显示的产品名（当前为"测试程序"） |
| 6 | `src/app/resources/icons/icon.ico` | 程序图标（嵌入 exe 版本资源） |
| 7 | `cmake/make_install_package.iss.in` 的 `SetupIconFile` | 安装包图标（可选） |

版本号文件 `src/app/version.txt` 不存在时会自动生成，且每次 configure
自动递增 build 号（tweak），无需手工维护。

## 可保留的示例

以下内容作为用法示例保留，新项目可在此基础上替换成自己的业务代码：

- `src/app` — 主窗口、对话框、日志面板的界面骨架
- `src/core/logger` — spdlog 封装（`LOG_INFO` 等宏），建议保留
- `src/core/auth`、`config`、`crashhandler` — 按需保留
- `demoes/` — 若干绘图小示例，可整体删除
- `config/calibration/calibration_sample.ini` — 构建后自动拷贝为
  `bin/calibration/calibration.ini`，是"配置文件随构建输出"的示例
- `tests/` — googletest 单元测试骨架

## 按需裁剪

- 顶层 `CMakeLists.txt` 中 3rdparty 的 `add_subdirectory`
  （spdlog、googletest、QCustomPlot、QXlsx）及对应 `target_link_libraries`
- 顶层 `CMakeLists.txt` 中 `find_package(Qt5 ...)` 的组件列表
- `src/app/CMakeLists.txt` 中 calibration 拷贝的 POST_BUILD 示例

## Linux 构建

前置条件：CMake ≥ 3.26（CMakePresets 为 version 8），以及
`find_package` 所需组件的开发包：

```bash
sudo apt install qtbase5-dev libqt5svg5-dev \
    libqt5serialport5-dev libqt5opengl5-dev
```

> 配置产物目录与 Windows 共用（`build/<presetName>`）。若在 WSL 等
> 共享同一源码树的场景下编译，务必指定独立目录，避免覆盖 Windows 侧
> 的 CMakeCache：

```bash
# 配置（独立目录，避免与 Windows 构建产物互相覆盖）
cmake -S . -B build/linux-ninja-debug -G Ninja \
    -DCMAKE_BUILD_TYPE=Debug
# 构建
cmake --build build/linux-ninja-debug
# 测试
ctest --test-dir build/linux-ninja-debug
```

- Linux 不读取 `local.cmake`，Qt 由系统路径解析；必要时用
  `-DCMAKE_PREFIX_PATH` 指定 Qt 安装位置
- 部署与打包（windeployqt / Inno Setup）仅 Windows 支持
