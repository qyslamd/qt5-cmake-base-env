# 常见问题

## 文档放在哪里？

安装目录下的 `docs/`。构建目录运行时，构建输出里的 `docs/` 也会被同步。

## 为什么图片不显示？

图片必须和 Markdown 文档位于同一个 `docs/` 树内，并使用相对路径引用。
查看器会拒绝 `docs/` 之外的本地路径。

## 为什么内部链接打不开？

确认目标文件以 `.md` 或 `.markdown` 结尾，并且位于 `docs/` 目录内。
带锚点的链接会先打开目标文档，再滚动到对应章节。

## 能离线使用吗？

可以。查看器不会下载远程图片，也不会在应用内打开网页；需要外链时交给系统浏览器。
