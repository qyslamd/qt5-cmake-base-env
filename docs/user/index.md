# 应用文档

这是 base env 的自包含文档中心。所有文档随应用一起发布，不依赖浏览器或网络。

> [!tip] 从这里开始
> 先阅读[快速开始](getting-started.md)，再按需查看[常见问题](faq.md)。

## 文档范围

| 文档 | 内容 |
| --- | --- |
| [快速开始](getting-started.md) | 界面入口、搜索、缩放、导出 |
| [常见问题](faq.md) | 文档位置、链接、图片和常见故障 |

## 设计原则

- 文档和图片放在安装目录的 `docs/` 下
- 内部 `.md` 链接在查看器内跳转
- `http`/`https` 链接交给系统浏览器
- 文档目录之外的本地资源不会被读取
